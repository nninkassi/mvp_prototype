Написаны автотесты на pytest + requests для эмуляции HTTP-запросов к локальному серверу.
Проверка RBAC: неавторизованные запросы к /profile/, /checkout/, /seller/stats/ корректно возвращают HTTP 302 (редирект на логин) без создания записей в БД.
Проверка бизнес-сценариев: регистрация, фильтрация каталога (GET /catalog/?category=1), добавление в корзину и оформление заказа с валидацией CSRF и данных форм.
Изоляция данных: проверка того, что продавец видит только свои товары.
